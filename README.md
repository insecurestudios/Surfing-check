# Surfing-check

## Project Goal
- To create a calculator that determines whether surfing is allowed based on student ability and weather conditions

## MVP Scope
- A GUI where users can input weather conditions and student ability  
- Error handling for invalid inputs  
- Calculation logic that displays whether or not surfing is allowed

## Tech Stack
- Java  
- Potentially other things, unknown for now

## Future Plans
- Weather API integration that automatically inputs information based on location  
- A mobile app  
- A more aesthetic GUI rather than just a functional one
